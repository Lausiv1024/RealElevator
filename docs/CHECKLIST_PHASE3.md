# フェーズ3 ゲーム内確認チェックリスト

クライアントを起動せずに実装とテスト（core のテスト・GameTest）まで済ませた機能の、ゲーム内での確認項目。
確認できたら `[x]` にする。不具合があれば、その項目の下に書いておく。

起動：`./gradlew :neoforge-1.21.1:runClient`

## ナッジング（強制戸閉）

準備：設置用ブロックで普通にエレベーターを設置する（戸閉アナウンスはオンのまま）。

- [ ] **反転5回で入る**：防具立てをかごの中、戸のすぐ内側（戸板に触れる位置）に置き、戸を開けたままにする。戸が閉まりかけては開き直すのを4回繰り返したあと、5回目の反転でナッジングに入る。
  - [ ] ブザーが1秒ごとに鳴る（かごの中から聞こえる。字幕は「エレベーターのブザー」）。
  - [ ] 閉まる速さが普通の半分くらい（5秒かけて閉まる）になる。戸閉アナウンスは流れない。
  - [ ] 防具立てに戸が触れると開き直すが、開ききるとすぐにまた閉まり始める（待たない）。
  - [ ] 防具立てを壊すと、そのまま閉まりきり、ブザーが止まる。
- [ ] **開放60秒で入る**：開ボタンを右クリックで押し続ける。60秒たつと、ボタンを押したままでも閉まり始め、ブザーが鳴る。
  - [ ] ナッジング中は、開ボタンを押しても開かない（車椅子用操作盤の開ボタンも）。
  - [ ] ナッジング中に、そのかごのいる階の乗場の▲▼を押しても開かず、チャイムも鳴らない。
  - [ ] 出入口に立ったままでも（ビームの範囲にいても）閉まり始める。体に戸が触れると開き直し、またすぐ閉まり始める。
- [ ] **数え直し**：反転を4回させたあと、物をどけて閉まりきらせる。次に開いたとき、また4回反転してもナッジングに入らない。
- [ ] **ほかのプレイヤーから見ても**同じ速さで閉まり、戸がガタつかない（マルチプレイが確認できれば）。
- [ ] **車椅子用で開いたとき**：車椅子用操作盤で呼んでナッジングに入っても、ナッジングの速さ（5秒）で閉まる。
