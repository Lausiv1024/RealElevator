# フェーズ3 ゲーム内確認チェックリスト

クライアントを起動せずに実装とテスト（core のテスト・GameTest）まで済ませた機能の、ゲーム内での確認項目。
確認できたら `[x]` にする。不具合があれば、その項目の下に書いておく。

起動：`./gradlew :neoforge-1.21.1:runClient`

## 強制戸閉

準備：設置用ブロックで普通にエレベーターを設置する（戸閉アナウンスはオンのまま）。

- [x] **反転5回で入る**：防具立てをかごの中、戸のすぐ内側（戸板に触れる位置）に置き、戸を開けたままにする。戸が閉まりかけては開き直すのを繰り返し、5回目の反転では普通の速さで開ききってから、強制戸閉で閉まり始める（一瞬で開いたりしない）。
  - [x] ブザーが1秒ごとに鳴る（かごの中から聞こえる。字幕は「エレベーターのブザー」）。
  - [x] 閉まる速さが普通の半分くらい（5秒かけて閉まる）になる。戸閉アナウンスは流れない。
  - [x] 防具立てに戸が触れると開き直すが、開ききるとすぐにまた閉まり始める（待たない）。
  - [x] 防具立てを壊すと、そのまま閉まりきり、ブザーが止まる。
- [x] **開放60秒で入る**：開ボタンを右クリックで押し続ける。60秒たつと、ボタンを押したままでも閉まり始め、ブザーが鳴る。
  - [x] 強制戸閉中は、開ボタンを押しても開かない（車椅子用操作盤の開ボタンも）。
  - [x] 強制戸閉中に、そのかごのいる階の乗場の▲▼を押しても開かず、チャイムも鳴らない。
  - [x] 出入口に立ったままでも（ビームの範囲にいても）閉まり始める。体に戸が触れると開き直し、またすぐ閉まり始める。
- [x] **数え直し**：反転を4回させたあと、物をどけて閉まりきらせる。次に開いたとき、また4回反転しても強制戸閉に入らない。
- [x] **ほかのプレイヤーから見ても**同じ速さで閉まり、戸がガタつかない（マルチプレイが確認できれば）。
- [x] **車椅子用で開いたとき**：車椅子用操作盤で呼んで強制戸閉に入っても、強制戸閉の速さ（5秒）で閉まる。

## 運転と休止（運転切替盤）

準備：エレベーターを3階床以上で設置する（普通仕様でも高速仕様でもよい）。クリエイティブの「機能的ブロック」タブにある「エレベーター運転切替盤」を置き、隣にレバーを付けてオンにする。

- [x] **見た目**：運転切替盤の正面は16pxのドット絵で、信号があるとランプが緑、ないと暗い赤になる。向きは置いたプレイヤーの方を向く。ツルハシで壊すと運転切替盤が手に入る。
- [x] **つなぐ**：保守用レンチを持ってしゃがみながら乗場の操作盤のあたりを右クリックすると「エレベーターを選びました」と出る（リニューアルの画面は開かない）。そのまま運転切替盤を右クリックすると「つなぎました」と出る。
  - [x] しゃがまずにレンチで運転切替盤を右クリックすると、「通常運転」「休止中」「どのエレベーターにもつないでいません」のどれかが出る。
  - [x] 高速仕様のエレベーターにもつなげる。
  - [x] レンチの説明（ツールチップ）に、運転切替盤のつなぎ方が出る。
- [x] **走行中に休止へ**：遠い階を呼んで走り出したところでレバーを切ると、止まれる最寄りの階に止まって戸が開く。チャイムとアナウンスは鳴らない。
  - [x] 戸は10秒ほど開いてから閉まる（戸閉アナウンスなし）。
  - [x] 休止中は、かごと乗場の階床表示器が「--」になり、ホールランタンとボタンのランプは消えている。乗場ボタンや行先ボタンを押しても点かず、かごは動かない。
  - [x] かごの開ボタンでは戸が開く。閉ボタンで閉まる。
- [x] **止まっているときに休止へ**：戸が閉まって止まっているときにレバーを切ると、その階で戸が開き、10秒後に閉まる。
- [x] **通常運転に戻す**：レバーを入れると、表示器に階が出て、呼べるようになる（休止前の呼びは消えている）。
- [x] **外す**：しゃがみながらレンチで運転切替盤を右クリックすると「外しました」と出て、レバーを切っても休止しなくなる。運転切替盤を壊したときも同じ。
- [x] **保存**：つないだままワールドを開き直しても、つなぎと休止の状態が残る。

## ランディングオープン

準備：設置用ブロック（またはリニューアル）の設定画面で「ランディングオープン」をオンにする（既定はオフ）。

- [x] **開き始め**：行先の階に着く直前（0.75秒前、床があと2pxくらい）で、かごの戸と乗場の戸が一緒に開き始める。かごはそのまま着床し、床がぴったり合う。
  - [x] そのとき行先ボタンのランプが消え、到着アナウンス（「◯階です」）が流れる。到着チャイムは二重に鳴らない。
  - [x] ホールランタンが、戸が開き始めたときから点く。
- [x] **乗り降り**：戸が開き始めてすぐに降りても、引っかかったり落ちたり巻き戻ったりしない（上り・下りの両方）。乗り込むときも同じ。
- [x] **開き始めてから着床までの操作**：その間に開ボタンを押すと効く。今いる階の乗場ボタンを押すと、登録せずに開いたままになる。
- [x] **オフのとき**：今までどおり、着床してから戸が開き始める。
- [x] **リニューアル**：保守用レンチのメニューでオン／オフを切り替えると、その次の到着から変わる。ワールドを開き直しても設定が残る。
- [x] **サーバーが重いとき**（できれば）：重いワールドやマルチプレイでも、かごの動きと戸の開き始めがずれない。
